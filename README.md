## Why did I build this?
I got tired of letting AI write the code for me and me having no clue what garbage it has spit out. So I've gone down the road of picking a project, let it be as simple as a URL shortner but actually writing every single line of code by hand. Raw dog it like the old days.

The goal is not to ship as fast as possible.
The goal is to sit and struggle through the pain of learning NOW so I don't ship AI slopped garbage LATER.

And become just a better engineer along the way.
